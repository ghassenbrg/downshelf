      Good to know

      How patterns work
      • * matches anything. , means “or”.
      • *.google.com matches google.com and every subdomain.
      • github.com/org/* matches one part of a site.
      • *.pdf, invoice-* match file names.
      • Website and URL rules check both the file’s link and the page you downloaded it from.
      • In quick add, join conditions with &: *.github.com & *.zip → Releases
      Saving outside the Downloads folder

      Chrome only lets extensions choose folders inside your download location. Downshelf follows that rule. If you want files to land elsewhere, you can set this up yourself:

      1. Move the download location up a level. In chrome://settings/downloads, set Location to a parent folder (for example your home folder). Then use destinations like Documents/PDF or Downloads.
      2. Link a folder into Downloads. Create a link inside Downloads that points elsewhere, then use the link’s name as the destination.
        macOS / Linux: ln -s ~/Projects ~/Downloads/Projects Windows (Command Prompt): mklink /J "%USERPROFILE%\Downloads\Projects" "D:\Projects"

      These are changes to your own computer; Downshelf can’t make them for you.

      Other download extensions

      If several extensions try to choose download folders, Chrome uses the one installed most recently. Disable other download managers if your rules seem to be ignored.
