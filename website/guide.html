Guide

Everything you need to sort your downloads with Downshelf.

Install

Chrome Web Store: the listing is on its way. Until it's live, install the latest release:

  1. Download downshelf-chrome-vX.Y.Z.zip from the latest release and unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and select the unzipped folder.
  4. Pin Downshelf from the puzzle-piece menu for one-click access.

Writing rules

Type a rule into Quick add on the settings page, or use New rule for a guided form.

PatternMatches
example.comexample.com and www.example.com
*.google.comgoogle.com and every subdomain
github.com/acme/*everything under /acme on github.com
*.pdfany PDF file
invoice-*, receipt-*names starting with either prefix
images, archiveswhole families of file types
*.github.com & *.zipboth conditions at once

Website and URL rules check the download link, where it redirects to, and the page you downloaded from — so drive.google.com catches Drive files served from other Google servers.

Folders can use variables: {domain}, {host}, {category}, {ext}, {year}, {month}, {day}, {date}.

Priority

Rules are checked from top to bottom; the first match wins. Drag rules to reorder them, or click Sort by specificity. To keep some files out of a broad rule, add a more specific rule above it with the destination Downloads.

Example: Google Flow downloads

Flow runs at labs.google. Add this rule and every clip you download from Flow lands in Downloads/AI/Flow:

labs.google → AI/Flow

Saving outside the Downloads folder

Chrome only lets extensions choose folders inside your download location, and Downshelf follows that rule. You can still send files elsewhere with a one-time change on your computer:

  1. Move the download location up a level. In chrome://settings/downloads, set Location to a parent folder such as your home folder. Destinations like Documents/PDF are then relative to it.
  2. Link a folder into Downloads. Create a link inside Downloads that points elsewhere, then use the link's name as the destination. 
    # macOS / Linux
ln -s ~/Projects ~/Downloads/Projects

:: Windows (Command Prompt)
mklink /J "%USERPROFILE%\Downloads\Projects" "D:\Projects"

Troubleshooting

  • A file went to the wrong place: paste its link (from chrome://downloads) into Test a download to see which rule matched.
  • Rules seem ignored: another download extension may be choosing folders. Chrome uses the most recently installed one.
  • Chrome asks where to save: that's Chrome's “Ask where to save each file” setting; the dialog opens in Downshelf's folder.
