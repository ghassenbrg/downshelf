# Support

For questions and bugs, open a [GitHub issue](https://github.com/ghassenbrg/downshelf/issues)
using the matching template. Include:

- the Downshelf and Chrome versions and your operating system;
- the rule(s) involved, as shown in the rule list;
- what **Test a download** says for the link (remove private tokens from URLs).

The [guide](https://ghassenbrg.github.io/downshelf/guide.html) covers
patterns, priority and saving outside the Downloads folder. For security
reports, see [SECURITY.md](SECURITY.md).
