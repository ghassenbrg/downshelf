# Security policy

## Supported versions

Security fixes go into the latest release on `main` and are shipped through
the Chrome Web Store. Older versions are not patched.

## Reporting a vulnerability

Please don't open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/ghassenbrg/downshelf/security/advisories/new)
for this repository. If that's unavailable, contact the maintainer through the
email on their GitHub profile with **Downshelf security report** in the
subject.

Include the affected version, steps to reproduce or a proof of concept, the
impact, and any suggested fix. We will acknowledge valid reports, investigate
privately, and coordinate a fix and disclosure timeline with you.
