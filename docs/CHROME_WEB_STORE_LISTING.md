### Description

```text
Downshelf puts every download in the right folder automatically, the moment it arrives.

Write simple rules like:
  github.com/my-org/*   →  Development/MyOrg
  *.github.com          →  Development/GitHub
  labs.google           →  AI/Flow
  invoice-*, receipt-*  →  Finance/{year}
  *.pdf                 →  Documents/PDF

MATCH ON ANYTHING
• Websites and their subdomains (*.google.com)
• A section of a site (example.com/reports/*)
• File names with wildcards (*.pdf, invoice-*)
• File types: documents, images, video, audio, archives, installers and more
• Combine conditions: *.github.com & *.zip → Releases

PREDICTABLE PRIORITY
Rules are checked from top to bottom and the first match wins, like email filters. Drag to reorder. New rules are placed above broader ones automatically, and Downshelf warns you when a rule can never fire because another rule catches its files first.

TEST BEFORE YOU TRUST
Paste any link or file name into “Test a download” to see exactly where it would go, which rule matched, and why.

MADE TO BE EASY
• Quick add: type “*.pdf → Documents/PDF” and press Enter
• Folder variables: {domain}, {year}, {month}, {category} and more
• Pause sorting from the toolbar, see rules for the current site, and check recent downloads
• Export and import your rules
• Light and dark mode

PRIVATE BY DESIGN
No account, no analytics, no network requests. Your rules and history stay on your computer.

GOOD TO KNOW
Chrome lets extensions create folders inside your download location, so Downshelf sorts files into subfolders there. The guide explains how to send files to folders elsewhere on your computer.

Open source (MIT): https://github.com/ghassenbrg/downshelf
```

## Privacy practices tab

### Single purpose

```text
Downshelf automatically saves each download into a subfolder of the user's download folder, chosen by rules the user writes (by website, URL, file name or file type).
```

### Permission justifications

| Permission | Justification |
| --- | --- |
| `downloads` | Required to choose the destination folder of each new download through chrome.downloads.onDeterminingFilename, which is the extension's single purpose. |
| `storage` | Stores the user's rules, settings and a short local history of sorted downloads (last 30) with chrome.storage.local. Nothing leaves the device. |
| `activeTab` | When the user opens the toolbar popup, reads the current tab's address to show which rules apply to that site and to offer "New rule for this site". The address is not stored or transmitted. |

**Host permissions:** none.

**Remote code:** No, I am not using remote code. All JavaScript is included
in the package. There is no `eval`, and no scripts are loaded from the
network. The build validator enforces this.

### Data usage

Downshelf does not collect or transmit user data. It processes download URLs,
referrers and file names **locally** to choose a folder, and keeps a 30-entry
history on the device. Nothing is sent to the developer or any third party.

- **What user data do you plan to collect?** Leave every category unchecked.
  Data that never leaves the user's device is not "collected" under the
  Chrome Web Store definition, and Downshelf has no network access at all.
  If the dashboard's definitions change, re-evaluate "Web history" (the local
  activity history) before submitting.
- **Certifications:** check all three:
  - I do not sell or transfer user data to third parties, outside of the approved use cases.
  - I do not use or transfer user data for purposes that are unrelated to my item's single purpose.
  - I do not use or transfer user data to determine creditworthiness or for lending purposes.

## Test instructions for reviewers (optional field)

```text
No account or setup is needed. After install, the options page opens with starter rules.
1. Download any PDF (e.g. https://www.w3.org/WAI/ER/tests/xhtml/testfiles/resources/pdf/dummy.pdf). It is saved to Downloads/Documents/.
2. On the options page, type "w3.org → Test/W3C" into Quick add and press Enter, then download the same file again. It is saved to Downloads/Test/W3C/.
3. Paste the PDF link into "Test a download" to see which rule matches and why.
```
